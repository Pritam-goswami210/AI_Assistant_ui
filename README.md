# AI Core Selector (Sphere Interface)

An immersive, web-based system dashboard inspired by Iron Man's HUD telemetry. This project provides a sleek user interface to switch between three legendary AI personalities—**J.A.R.V.I.S.**, **F.R.I.D.A.Y.**, and **U.L.T.R.O.N.**—complete with simulated real-time diagnostic reporting.

## All the cool Features

* **Dynamic Core Toggling:** Smooth transitions when selecting between different AI entities (JARVIS, FRIDAY, and ULTRON).
* **Live Telemetry & Diagnostics:** Active visual monitoring panels displaying live metrics like FPS (60Hz), System Latency (12ms), Load Capacity (14%), and Core Temperature (38°C).
* **Synchronized State Engine:** Fully synchronized status trackers that switch into "System Standby" mode when inactive.
* **Cinematic Sound & Visuals:** Deep space sci-fi theme optimization with low-latency digital asset rendering.
